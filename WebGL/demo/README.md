# GPU 粒子系统

基于 Three.js 的 GPGPU 粒子渲染示例。二十余万个粒子的位置与速度完全在 GPU 上积分更新，CPU 每帧只负责提交几个 uniform，不参与任何逐粒子计算。

## 运行

整个页面是纯静态文件，Three.js 通过 importmap 从 CDN 加载，双击 `index.html` 即可在浏览器中打开，需要联网。

若习惯使用本地服务器，可在本目录执行：

```bash
python3 -m http.server 26418
```

随后访问 `http://127.0.0.1:26418`。

## 操作

- 左键拖动旋转视角，滚轮缩放，右键平移
- 移动指针并在控制面板将指针模式切换为吸引或排斥，粒子会向指针位置聚拢或散开
- 空格键暂停或恢复模拟
- 右上角面板可实时调整流场、寿命、渲染与后处理参数；粒子数量支持从 1.6 万到 105 万四档切换

## 实现要点

### GPGPU 乒乓模拟

模拟数据存放在两张 RGBA 浮点纹理中：`texturePosition` 的 xyz 通道存位置，w 通道存剩余寿命；`textureVelocity` 的 xyz 通道存速度，w 通道存该粒子的寿命上限。GPUComputationRenderer 为每个变量维护两个渲染目标，逐帧交替读写，实现 ping-pong 积分。模拟每步渲染两个全屏四边形，片元着色器对每个纹素执行一次粒子状态更新。

### 力学模型

- **curl noise 流场**：以三维单纯形噪声构造向量势场，中心差分求其旋度，得到无散度的旋涡型速度场。无散度意味着流场不会凭空产生或消灭密度，粒子云因此能保持绵延的絮状结构。采样坐标随时间漂移，流场形态随之缓慢演化
- **漩涡与扁平化**：绕竖直轴的恒定切向加速度与指向水平面的回复加速度，共同把粒子云整理成带旋臂的盘状星云
- **指针力**：以指针在水平面上的投射点为吸引子，施加随距离平方衰减的引力或斥力
- **阻尼**：速度按指数衰减，与帧率无关，保证不同刷新率下形态一致

### 一致重生

粒子寿命耗尽或逃出边界后，在盘面内随机重生。位置着色器与速度着色器各自独立判断重生条件，并以完全相同的表达式从纹素坐标与时间桶生成随机数，因此两个着色器在同一帧得出相同的新位置与新寿命，无需额外的同步通道。

### 渲染

粒子以 `THREE.Points` 绘制，顶点着色器从 GPGPU 纹理读出位置与速度，按速度大小在三段配色间插值，并按剩余寿命做淡入淡出。片元着色器以 `gl_PointCoord` 生成高斯形光斑，加色混合叠加。后处理链为 RenderPass、UnrealBloomPass 与 OutputPass，其中 OutputPass 负责 ACES 色调映射与 sRGB 输出。

## 环境要求

- 支持 WebGL2 与 `EXT_color_buffer_float` 扩展的浏览器，Chrome、Edge、Firefox、Safari 近年版本均可
- 粒子数量默认 26 万，桌面独显可尝试 105 万档
