# 风格扩展调研（第二期）

本项目已完成四种画面的实现与切换：方案 A 吉卜力晴海、方案 B 低多边形、方案 C 风之杖卡通、方案 D 半写实明亮，见 [设计候选方案.md](设计候选方案.md) 与项目根目录 README.md。本文档为第二期美术风格调研，筛选与已实现四种差异明显、且在 Three.js 中有明确落地路径的方向，编号自 E 起续接，供后续逐个实现。

筛选原则有三条：其一，视觉语言与已有四种拉开距离，避免同质的水面着色变体；其二，优先覆盖未使用过的技术方向，如后处理管线、顶点动画特性、发光后期；其三，参考图充足，风格特征可明确描述。

## 方案 E 浮世绘海浪

状态：已实现，见项目根目录 README.md。浪形与浪花的进一步深化思路见 [浮世绘海浪深化方案.md](浮世绘海浪深化方案.md)。

| 项目 | 内容 |
| --- | --- |
| 画面描述 | 葛饰北斋神奈川冲浪里式的平面化海浪，靛蓝三至四档平涂，浪峰卷起爪状浪花，米黄纸底天空，船为画面中的小小木色剪影 |
| 参考图 | [The Great Wave off Kanagawa](https://en.wikipedia.org/wiki/The_Great_Wave_off_Kanagawa)、[Smarthistory 原作解析](https://smarthistory.org/hokusai-under-the-wave-off-kanagawa-the-great-wave/)、[Artelino 版画资料](https://www.artelino.com/articles/the-great-wave.asp) |
| 水体处理 | 去光照或极弱光照，片元按波高平涂靛蓝色阶；浪花以弧形描边带近似原作的爪形图案，沿等高线生成 |
| 船与材质 | 船体压暗为木色剪影，两档着色，无高光 |
| 光照天空 | 米黄纸色天空，贝扣形云纹用平涂面片表现；整体接近无光影的平绘 |
| 技术要点 | 在方案 A 的 GPU 位移水面骨架上重写片元配色即可；浪花的爪形轮廓是成败关键，可用等高线描边加方向性扰动近似 |
| 风险与工作量 | 中。配色与色阶数量容易，浪花形状的风格化需要反复调校 |

## 方案 F 水彩纸本

状态：已实现，见项目根目录 README.md。

| 项目 | 内容 |
| --- | --- |
| 画面描述 | 画在纸面上的水彩海景，颜料有沉积边缘与晕染，高光留白，整体是手工绘画质感 |
| 参考图 | [Hand-Painted Watercolor Pieces in 3D](https://80.lv/articles/hand-painted-watercolor-pieces-in-3d)、[Artineering 水彩着色器](https://artineering.io/styles/watercolor)、[Nanotale 水彩三维场景](https://80.lv/articles/nanotale-a-watercolor-painting-in-3d)、[Watercolor Samurai 幕后](https://www.blendernation.com/2020/11/04/behind-the-scenes-watercolor-samurai/) |
| 水体处理 | 保留光照结果，后处理阶段做分区色彩量化、纸纹叠加、边缘沉积加深与纸色留白高光 |
| 船与材质 | 常规 PBR 或卡通材质均可，风格主要由后处理承载 |
| 光照天空 | 柔和日光，低对比 |
| 技术要点 | 引入 EffectComposer 后处理链，自定义 pass 实现：屏幕空间边缘检测勾线、程序化纸纹、按亮度分区量化与噪声扰动的颜料边缘；three.js 后处理骨架成熟 |
| 风险与工作量 | 大。参数空间大，调校周期最长，但成果风格上限高，且后处理链建好后可同时服务水墨、素描等更多方向 |

## 方案 G 像素艺术

状态：已实现，见项目根目录 README.md。

| 项目 | 内容 |
| --- | --- |
| 画面描述 | 复古像素游戏画面，海面与船以大像素呈现，色板有限，波浪动画呈帧步进 |
| 参考图 | [Fishing Boats Pixel Pack](https://mutterpixel-studio.itch.io/fishing-boats-pack-pixel-game-assets)、[Military Boats Pixel Art](https://craftpix.net/freebies/free-top-down-military-boats-pixel-art/)、[Animated Boat](https://www.pinterest.com/pin/animated-boat-by-lylian-leutard--2111131070809458/) |
| 水体处理 | 三维渲染结果经像素化后处理，可叠加法线与深度边缘的单像素描边 |
| 船与材质 | 任意现有材质，像素化后风格统一 |
| 光照天空 | 现有任一配置，建议配低对比晴天 |
| 技术要点 | three.js 官方提供 RenderPixelatedPass 示例（[webgl_postprocessing_pixel](https://threejs.org/examples/#webgl_postprocessing_pixel)），含像素尺寸、法线边缘强度与像素吸附控制，直接复用；波浪动画时间按帧率量化可强化复古感 |
| 风险与工作量 | 小。官方组件支撑，主要工作是像素尺寸与调色板取舍 |

## 方案 I 黏土定格动画

状态：已实现。实现时编号调整为方案 H（黏土定格动画），见项目根目录 README.md。

| 项目 | 内容 |
| --- | --- |
| 画面描述 | 橡皮泥手工场景：圆润体块、表面细微凹凸、柔和棚拍光、浅景深，动画带轻微的定格顿挫 |
| 参考图 | [Claymation 完全指南](https://aplusc.tv/blog/what-is-claymation-animation-the-complete-guide/)、[橡皮泥立体场景](https://www.dreamstime.com/charming-d-plasticine-diorama-celebrating-stopmotion-animation-craft-tactile-render-style-miniature-stop-motion-set-small-image400265662) |

| 船与材质 | 船体几何膨胀圆润化，材质高粗糙度加指纹理凹凸 |
| 光照天空 | 棚拍式柔和平行光加大面积环境光，浅景深可选 |

| 风险与工作量 | 中。与现有 PBR 管线高度兼容，主要成本在凹凸与圆润化的度 |

## 技术方向归纳

| 技术方向 | 代表方案 | 对现有骨架的改动 |
| --- | --- | --- |
| 后处理管线 | F 水彩、G 像素、H 低保真 | 引入 EffectComposer 与自定义 pass，建好后可复用于素描、油画等更多方向 |
| 片元着色风格化 | J 水墨 | 复用方案 A 的 GPU 位移水面骨架，仅重写配色与浪花逻辑 |
| 材质与动画特性 | I 黏土 | 材质凹凸与动画时钟量化，浮力逻辑不变 |
| 发光后期 | K 合成波 | UnrealBloomPass 与网格线着色器 |
| 极简着色 | L 扁平矢量 | 方案 A 的裁剪版 |

方案 E 已实现并深化出立体爪浪，见 [浮世绘海浪深化方案.md](浮世绘海浪深化方案.md)。

## 对比与建议

| 维度 | E 浮世绘 | F 水彩 | G 像素 | H 低保真 | I 黏土 | J 水墨 | K 合成波 | L 扁平 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 视觉差异化 | 最高 | 高 | 高 | 高 | 高 | 高 | 高 | 低 |
| 实现工作量 | 中 | 大 | 小 | 中 | 中 | 中 | 中 | 小 |
| 技术复用度 | 高 | 引入后高 | 高 | 高 | 高 | 高 | 中 | 高 |
| 清澈蓝海契合 | 高 | 高 | 高 | 中 | 高 | 低 | 低 | 高 |
| 后续扩展价值 | 中 | 最高 | 中 | 中 | 中 | 中 | 低 | 低 |

建议按 G、E、I 的顺序推进。像素艺术工作量最小且有官方组件支撑，适合先打通后处理管线；浮世绘的美术辨识度在八个候选中最高，且与靛蓝海面的题材天然契合；黏土风格与现有 PBR 管线兼容度最好，并能引入动画步进这一新特性维度。水彩上限最高但调校成本大，建议放在后处理管线成熟之后。水墨与合成波偏离清澈蓝海的项目定位，作为风格实验视兴趣决定。
