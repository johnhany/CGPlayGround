# 海面小船场景设计候选方案

基于 Three.js 实现海面上随波浪摇摆的小船场景。整体定位为高质量 CG 渲染，画面风格允许偏向动画风，但水体必须呈现清澈的蓝色，且光照充足。本文档汇总网络检索得到的参考图片与技术资料，明确画面元素、风格方向与预期效果，并给出四种候选方案及对比结论。

状态：本项目定位为渲染风格试验场，页面内提供风格切换按钮。四种候选方案 A、B、C、D 均已实现，见项目根目录 README.md。第二期扩展调研筛出八个新方向，见 [风格扩展调研.md](风格扩展调研.md)。

## 1. 目标概述

- 技术栈：Three.js（沿用 WebGL/demo 的纯静态页面与 CDN importmap 组织方式）
- 核心内容：程序化海面波浪、漂浮其上的小船、天空与光照环境
- 画面基调：晴朗白天，高照度直射阳光，水体为通透的蓝青色渐变，整体明快干净
- 交互形态：轨道相机拖动缩放，参数面板可实时调整风浪强度、太阳高度等
- 性能目标：桌面端 60 帧/秒，中端核显不低于 30 帧/秒

## 3. 画面元素清单

### 3.1 主体

- 小船：帆船或木质小渔船，尺寸约占画面高度四分之一，位于视觉中心偏下
- 船体运动：随波的升沉、纵摇、横摇三自由度摆动，附加轻微的阻尼回正与惯性感

### 3.2 水体

- 波形：多组方向、波长、振幅各异的波叠加，近处细节丰富、远处平缓
- 颜色分层：深水蓝、中层青蓝、波峰浅青的深度渐变，视线掠射角处反射天空色
- 透明感：近岸或波峰薄处透光，水中隐约可见水下亮色
- 泡沫：波峰白沫与船体周围环形尾迹泡沫
- 高光：太阳方向的细碎闪烁光斑，即 sun glitter
- 可选：水下焦散、船首浪花粒子

### 3.3 天空与光照

- 晴空：大气散射渐变，天顶深蓝、地平线浅青白
- 云：大块积云若干，底部略带灰蓝，边缘亮
- 太阳：高角度直射平行光，色温暖白，配合环境光或半球光补足阴影面亮度
- 可选：镜头光斑、远景岛屿剪影、海鸥剪影

| 波峰与浅水 | 0x53c8dd | 青绿亮色，透光区域 |
| 波峰透光亮部 | 0x9ceee8 | 伪次表面散射的高亮青白 |

| 天顶 | 0x4aa3d8 | 明亮但不刺眼的天蓝 |
| 阳光 | 0xfff2dc | 暖白直射光 |

## 4. 预期效果

- 构图：相机略高于水面俯视，船与太阳方向呈 30 至 60 度夹角，水面占画面下三分之二
- 光照：正午偏后的强光，阴影清晰但不发黑，整体曝光明亮，ACES 色调映射下高光柔和
- 动画：波浪主周期 4 至 8 秒，船体摆动与波峰通过时间同步，无穿模与悬空
- 水体质感：第一眼呈现清澈的蓝青色，波峰有透光感，泡沫与闪烁提供细节活力
- 整体氛围：明快、宁静、略带童话感的夏日海面

## 5. 候选方案

### 方案 A：吉卜力式晴海

| 项目 | 内容 |
| --- | --- |
| 画面描述 | 大面积渐变蓝海面配大块积云，色块干净，光感充足，接近手绘动画背景的三维化 |
| 水体处理 | 波形平缓，Gerstner 波振幅小；着色以高度驱动的三段色渐变为主，几乎不反射环境，菲涅耳反射很弱；泡沫为细白描边 |
| 船与材质 | 低多边形帆船，材质为低粗糙度的卡通化 PBR，颜色明快，阴影面用环境色补光 |
| 光照天空 | Sky 着色器晴天配置，程序化积云 billboard，强平行光加半球光 |
| 技术要点 | 顶点位移加自定义片元着色；云用少量面片与渐变贴图；后期仅 ACES 与轻微泛光 |
| 风险与工作量 | 风险最低。难点在于渐变配色的品味，需要反复调色 |

### 方案 B：低多边形几何海

| 项目 | 内容 |
| --- | --- |
| 画面描述 | 全场景由几何体块构成，波浪呈折面，配色简洁明快，现代插画感 |
| 水体处理 | 波浪网格刻意保持低细分，顶点色按波高分三档平涂，关闭平滑着色保留折面感；泡沫为折面边缘的白色窄条 |
| 船与材质 | Quaternius 或 Kenney 的低多边形船模，MeshLambert 或 Flat Shading 材质 |
| 光照天空 | 纯色渐变天空或简单 Sky，平行光硬阴影 |
| 技术要点 | 波形函数与顶点色联动；无需复杂反射；可用顶点动画代替着色器位移，实现最简单 |
| 风险与工作量 | 工作量最小，一天内可出效果。上限也最低，画面容易显得单薄 |

### 方案 C：风之杖式卡通海

| 项目 | 内容 |
| --- | --- |
| 画面描述 | 强烈的赛璐璐卡通海面，旋涡浪花与描边轮廓，游戏化的装饰美感 |
| 水体处理 | 波形中等起伏；着色分两到三档色带，边界硬；泡沫用程序化噪声纹理沿波峰与船周生成旋涡状图案，风格化程度最高 |
| 船与材质 | 卡通船模加轮廓描边，材质用 toon 渐变映射 |
| 光照天空 | 明亮平光，阴影用两档色阶表现，天空饱和度高于其他方案 |
| 技术要点 | toon 渐变映射与 outline pass；泡沫纹理的流动与消散需要专门的着色逻辑；波峰浪花用雅可比量阈值触发 |
| 风险与工作量 | 工作量中等偏上。风格化泡沫与描边的效果调校次数多，风格把握不当容易显得幼稚 |

### 方案 D：半写实明亮海

| 项目 | 内容 |
| --- | --- |
| 画面描述 | 皮克斯式明亮渲染，物理可信的水面光学但色彩经过艺术化提纯，质感最接近高质量 CG 短片 |
| 水体处理 | Gerstner 多波叠加，中等振幅；完整水体着色：深度吸收渐变、菲涅耳天空反射、太阳高光闪烁、基于波陡的伪次表面散射透光、 crest 与深度双通道泡沫；可选屏幕空间水下焦散 |
| 船与材质 | 稍高模数的船模，标准 PBR 材质，木纹与帆布质感，接触水面处有湿润深色渐变 |
| 光照天空 | Sky 大气散射加 Poly Haven 晴天 HDRI 环境光照，暖白强平行光 |
| 技术要点 | 水面着色器为四个方案中最复杂；反射用 cubemap 或简单程序化天空采样避免平面反射的开销；泡沫需两张噪声图流动混合 |
| 风险与工作量 | 工作量最大。着色器调试周期长，但成果上限最高，与项目内既有 Taichi 水体系列的画质追求一致 |

## 6. 方案对比与建议

| 维度 | 方案 A 吉卜力晴海 | 方案 B 低多边形 | 方案 C 风之杖卡通 | 方案 D 半写实明亮 |
| --- | --- | --- | --- | --- |
| 清澈蓝色水体契合度 | 高 | 中 | 中 | 高 |
| 光照充足契合度 | 高 | 高 | 高 | 高 |
| 动画风契合度 | 高 | 中 | 最高 | 中偏高 |
| 画质上限 | 中高 | 低 | 中高 | 最高 |
| 实现工作量 | 中 | 小 | 中大 | 大 |
| 技术风险 | 低 | 极低 | 中 | 中高 |

四案共用同一套骨架：Gerstner 波形、CPU 采样浮力、Sky 天空与轨道相机。差异集中在水面着色与船体材质上，因此可以先搭建共用骨架，再按选定方案实现着色层。

建议以方案 A 为首选。理由有三：其一，画面要求中的动画风、清澈蓝色与充足光照三个条件在方案 A 中同时达到最佳平衡；其二，着色器复杂度可控，波浪、浮力、云层各自独立，进度风险小；其三，该风格对反射与折射精度要求低，WebGL 环境下容易稳定达到 60 帧。

方案 D 可作为方案 A 完成后的进阶方向，两者骨架相同，升级成本主要是水面片元着色器与船体材质。若希望优先追求最强的视觉冲击力，则直接选方案 D。
