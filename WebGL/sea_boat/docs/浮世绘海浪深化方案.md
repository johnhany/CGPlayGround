# 浮世绘海浪深化方案

方案 E 已实现木版画式的色彩与线条语言，但浪的形体仍是物理涌浪，与浮世绘的图形化海浪存在差距。本文档分析差距并给出分层的改造路线，作为后续实现的依据。

状态：已根据实际截图重新组织方案 E。下文技术路线保留为历史设计；以本节与 README 的当前实现说明为准。

## 当前修订（2026-10-13）

- 从五档等高色带改成三档主色与坡向分区，取消逐色阶描边；片元解析波面，流线与浪唇使用 `fwidth` 抗锯齿。
- 修复爪浪横向折返：横向坐标保持单调，包络用于高度与卷曲。八个随机道具替换为一道主卷浪、两道次浪，固定布局与统一相位，不因相机转动传送。
- 旧顶点色烘焙写错数组，已用共享的片元颜料分区替代。浪根逐点采样同一位移后的海面，边缘渐降至水面。
- 修复贴花缩放轴：在 XZ 平面上逐点构造尺寸与位移。移除面向相机倾斜、远处放大和随机网格播撒，改为少量随浪峰推进的细分白沫贴片，使用透明度淡入淡出。
- 船、水面、卷浪、白沫、云与天空统一关闭色调映射，保留 sRGB 输出；提亮木色与纸帆，船用固定两档明暗。
- E 使用独立默认机位和船向，关闭自动环绕，收起面板；退出恢复之前的机位、船向、面板与环绕设置。窄屏风格按钮换行显示。
- 共享波面法线偏导由减法修正为累加，与位移函数的导数一致；船壳水线分色改为读取顶点坐标，湿润暗带不再累积修改基础颜料。
- `?style=E&time=0&paused=1` 可重现静态画面；暂停切换风格或调整风浪强度也刷新几何与浮力。

验收重点：不同风浪强度和时间下顶点有限、横向不折返、整段浪根与水面吻合；相同时间下结果不依赖相机或 dt；暂停切换与七种风格正常显示。

## 一、差距分析

对照神奈川冲浪里等作品，当前画面在五个层面存在差距：

| 层面 | 浮世绘特征 | 当前实现 | 差距 |
| --- | --- | --- | --- |
| 浪的形体 | 非对称：背坡长缓、前坡陡峭，波峰前倾卷曲，形似鹰爪 | 对称圆滑的正弦类涌浪 | 形态差异最大 |
| 浪花 | 离散的爪形图形元素，指尖圆钝、成组排列 | 噪声等高线条带，连续而非离散 | 缺少图形元件感 |
| 线条 | 全形勾勒：各色阶边界均有墨线，波面内部另有顺流向的细流线 | 仅浪花外缘一道墨线 | 缺等高墨线与流线 |
| 色彩 | 色阶内带板目晕染，边界向浅色侧渗出短渐变 | 硬边色带 | 缺渗透感 |
| 运动 | 浪群有主次，一道主导浪压过画面，方向高度一致 | 各波振幅恒定、方向分散 | 缺主角浪 |

关键认知：高度场无法表达真正的翻卷悬垂，卷曲感只能通过形体前倾加浪花贴花加浪唇阴影的组合暗示，或者引入少量手工雕刻的英雄卷浪网格。

## 二、技术路线

### 2.1 波形层：改造 CPU 与 GPU 共用的波函数

波形改动必须同步进 waves.js 的 JS 采样器与 water_common.js 的 GLSL 片段，浮力才能保持贴合。

1. 谐波锐化：波高由正弦改为叠加负相位的二次谐波，即 h 等于 a 乘以 sin f 减 s 乘 sin 2f 的一半，s 取 0.25 至 0.4。效果是前坡变陡、后坡变缓、波峰变尖、波谷展平，正是浮世绘浪的非对称基础形。解析可求值，浮力采样无碍。
2. 波峰前倾：在位移的水平分量上叠加随波高变化的偏移，即水平前移量等于 lean 乘以 h 除以 a，lean 取 0.2 至 0.35 倍振幅，方向沿波传播方向。波峰整体向前探，配合前坡的陡度产生卷曲趋势。此项只改位移公式，切线与法线按差分或解析同步更新。
3. 波群包络：给主导浪乘以慢变包络 E 等于 1 减 g 乘 cos 下标 g 的相位，g 取 0.3 至 0.4，包络周期取主导浪周期的四至八倍。画面上每隔十几秒涌起一道显著高于其余浪的主角浪，重现原作的主次构图。
4. 方向收敛：把五组波的方向集中到主方向正负 35 度以内，波长比拉开，读感为浪从一个方向推进。

### 2.2 浪花层：爪形贴花系统

把浪花从连续噪声条带升级为离散图形元件。

1. 纹理库：canvas 绘制四至六种爪形浪花贴图，母题为三至五根内嵌圆弧指尖组成的爪排，米色纸白填充加深靛轮廓，风格与云纹一致。
2. 播撒逻辑：CPU 端以约三米步长的粗网格采样波面，当采样点波高上穿阈值且局部陡度达标时，从对象池取出贴花实例，放到波面切平面上，朝向沿波传播方向，随机镜像与缩放。
3. 生命周期：淡入约 0.3 秒，存活 1.5 至 3 秒后淡出，期间贴花随波面高度更新位置，产生浪花随浪推进又消散的观感。对象池规模约六十四个，InstancedMesh 一次绘制。
4. 浪尖白帽：更高阈值的触发放置更小的纯白贴花，表现浪尖破碎分离的白帽。

贴花纯装饰，不参与浮力，无同步成本。

### 2.3 线条层：全形勾勒

1. 等高墨线：在每个色阶阈值处叠一道细墨线，line 等于 1 减 smoothstep 的窄带，五档色阶共四道线，线宽以屏幕空间恒定为准，用 fwidth 抗锯齿。
2. 内部流线：以主导浪的相位构造条纹，即相位除以波长乘以密度取小数落在窄带内画细线，条纹天然沿波形弯曲，再叠域扭曲让线条摇曳，模拟原作波面内顺流向的细线。
3. 墨线颜色用比所在色阶深一档的靛色而非纯黑，保持套印感。

### 2.4 色彩层：板目晕染

把硬边色带改为边界不对称过渡：向深色侧保持 0.02 的窄抗锯齿，向浅色侧展开 0.08 至 0.12 的渐变，模拟拓印颜料向浅色侧渗出的板目晕染。深靛主色可微调向普鲁士蓝。

### 2.5 可选层：英雄卷浪网格

若静态暗示仍不足，可在高度场之外布置一至两道手工参数化的卷浪网格：以参数曲面 r 随角度变化构造翻卷剖面，浪唇一圈放置爪形贴花，沿弧线路径缓慢推进后消散重置。成本最高，视觉收益也最大，建议作为独立迭代。

## 三、约束与取舍

- 所有波形公式改动需在 JS 与 GLSL 两处同步，建议把锐化与前倾参数做进 uniform，避免两端漂移。
- 高度场无悬垂，卷曲感依赖前倾、浪唇下方加一道暗色假阴影与爪形贴花的组合暗示。
- 贴花播撒粒度需设最小间距，避免浪峰密集处贴花重叠成片。
- 波形锐化后振幅包络会放大瞬时波高，浮力采样与色阶阈值均按包络后的实际波高工作，无需额外处理。
