# 水面渲染 demo 开发方案

## 目标

在 Taichi 中构建由浅入深、由简入繁的水面渲染与计算 demo。
每个 demo 都是独立、完整且适合展示的小场景，具有背景、光照、
交互镜头、参数面板和默认展示视角。模拟负责运动与交互，渲染负责
水的材质、空间感和视觉质量，两条路线同步推进。

## Demo 序列

| Demo | 场景与预期效果 | 图形学技术 | 计算数学与模拟技术 |
|---|---|---|---|
| 01 庭院浅池：基础波纹 | 石质浅池、池底卵石、暖色天空；圆形波纹持续运动，环境映在水面，池底随波纹扭曲 | 高度场、水面法线、Fresnel 反射、折射、深度水色、太阳高光 | 正弦波叠加、径向衰减、解析导数；直接计算波形 |
| 02 雨落池塘：交互波纹 | 点击生成波纹，雨滴形成交错涟漪；池壁反射 | 水面拾取、细节法线、雨滴视觉、基础水材质复用 | 二维波动方程、有限差分、双缓冲、阻尼、固定时间步与稳定性条件 |
| 03 日落海面：Gerstner 波浪 | 风浪可调，浪峰更尖、浪谷更宽，夕阳形成长条高光 | 多尺度几何与法线、环境反射、地平线、距离雾、远处细节衰减 | Gerstner 参数化波、解析切线与法线、波长与频率关系、陡峭度约束 |
| 04 浮标与小船：物体交互 | 浮标起伏，船体俯仰与横摇；拖动船体形成局部尾迹 | 水面遮挡、接触泡沫、尾迹、扰动叠加 | 多点浮力、阻力、刚体力矩、数值积分；先单向响应，再近似反馈 |
| 05 风场海洋：FFT 海浪 | 多尺度且方向分散的海浪，微风、涌浪和强风预设 | 近中远景分层、网格 LOD、波峰泡沫、远景抗闪烁 | 随机波谱、复数频域、色散关系、二维逆 FFT、水平位移、Jacobian |
| 06 沙滩与礁石：近岸交互 | 波浪进入浅水、绕过礁石；水线推进与退去，留下湿沙与泡沫 | 岸线过渡、湿沙、浅水透明度、泡沫带、地形深度 | 带海底地形的浅水方程、有限体积法、通量、CFL 条件、干湿边界、开放边界 |
| 07 潜入水下：水体内部 | 镜头穿过水面，远处变蓝绿，池底出现焦散，水面形成天空窗口 | 折射、全反射、吸收与散射、体积光、焦散、介质切换 | Snell 定律、Beer–Lambert 衰减、视线积分；先近似焦散，再追踪光线 |
| 08 击水与喷溅：水花效果 | 石块落水或船头撞浪，产生水滴、泡沫和回落波纹 | 水滴高光、粒子透明合成、拖尾、粒子遮挡 | 弹道粒子、重力与阻力、碰撞、事件发射、回落时向高度场注入扰动 |
| 09 水槽冲击：三维流体 | 水流撞击障碍物，出现水团、薄片、断裂和回落 | 表面重建、屏幕空间流体或 Marching Cubes、厚度折射、泡沫与水滴 | PBF 或 SPH、邻域搜索、密度约束、迭代求解、黏性、涡度、固体边界 |

## 技术边界

1. 简单二维波动方程适合局部扰动、传播和反射，不能准确表达深水
   海浪色散；Gerstner 和 FFT 分别解决可控造型与海洋统计外观。
2. 船体第一版读取波面计算浮力，用局部扰动近似尾迹；随后增加排水
   与反馈，完整流固耦合属于后续扩展。
3. 岸边泡沫颜色不能替代水线运动；浅水方程需要干湿边界处理。
   高度场无法表现卷浪空腔和断裂水片。
4. 弹道水花粒子与连续三维流体分开实现；三维流体先限制在小水槽，
   集中展示近景细节。
5. 焦散、体积光、泡沫等先实现实时外观近似，再逐步增加物理准确性。

## 所有 demo 的展示要求

| 功能 | 要求 |
|---|---|
| 背景 | 天空或环境贴图、太阳、地面或海底、有比例感的物体 |
| 镜头 | 旋转、平移、缩放、复位；按场景增加自由飞行 |
| 预设视角 | 全景、贴近水面的低角度、俯视；水下 demo 增加水下视角 |
| 自动展示 | 慢速环绕与预设事件，启动后立即呈现核心效果 |
| 光照 | 晴天、日落、阴天；共享太阳方向、曝光和色调映射 |
| 操作 | 暂停、单步、重置、时间速度与关键效果参数 |
| 录制 | 固定随机种子、固定时间步、截图和逐帧导出 |
| 质量 | 模拟分辨率、渲染分辨率、反射质量、粒子数量分别管理 |

## Taichi 实现路线

- Taichi kernel 承担波形、网格与粒子更新、FFT、流体求解和自定义着色。
- GGUI 管理窗口、输入和参数面板；复杂水材质增加自定义光线求交、
  反射折射和后处理，不仅依赖基础 mesh 着色。
- 初期场景由平面、盒子、球体和简单地形构成，限制渲染器工作量。
- 模拟与渲染分辨率分离，低频运动与高频法线分别处理。
- 在本机实际支持的 GPU 后端上验证性能，并保留 CPU 调试路径。
  不预先承诺帧率；在实现后测量。
- 引擎源码 `/Users/john/git/taichi` 只读，图索引项目名为
  `Users-john-git-taichi`，demo 使用 uv 环境中的已发布 Taichi 包。

## 开发顺序与综合展示

第一阶段：01 → 02 → 03，形成水材质和展示框架。

第二阶段：04 → 05 → 06，增加海浪、物体和环境交互。

第三阶段：07 → 08 → 09，增加水下、飞溅和连续三维流体。

最后整合「灯塔海湾」：远处 FFT 海洋、近岸浅水、一艘可控小船、
局部飞溅，以及可潜入水下的镜头。各模块先独立验证，再整合。

## Demo 01 视觉升级路线

第一轮（已实现）：现代庭院构图、围墙和建筑背景、植物轮廓与分枝、实际几何倒角、
四采样空间抗锯齿。实现入口为 `water/demo_01.py`，默认 `--samples 4`，
可用 `--samples 1` 或面板开关进行对照。

第二轮（已实现）：GGX / Smith / Schlick PBR 材质、程序化 HDR 环境光照、
漫反射辐照度卷积与粗糙度预过滤反射、四采样太阳软阴影、短程接触 AO。
新增独立光照面板、日落预设与性能开关，说明见 `water/README.md`。

第三轮（已实现）：GGX 可见微表面采样的粗糙水面反射、中频高度波与
按像素覆盖尺寸过滤的细节法线、太阳折射到池底的光能累积焦散、线性
HDR Bloom 和可调暗角。新增 `WATER / FINISH` 面板及效果开关。
