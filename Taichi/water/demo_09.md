## 启动与展示

```bash
cd /Users/john/git/CGPlayGround/Taichi
uv sync --locked
uv run python water/demo_09.py
# 撞击立柱的近景
uv run python water/demo_09.py --preset impact
# 快速预览
uv run python water/demo_09.py --width 800 --height 500 --samples 1
# 无窗口截图
uv run python water/demo_09.py --headless --output output/tank.png
```

默认日间光照、960 × 600、单空间采样。打开窗口即可看到 0.8 m 高的水柱
在 2.0 × 1.0 m 水槽中溃塌：水流冲过槽底，约 0.4 秒后撞击中央立柱，
翻起水团与薄片，随后碎裂成水滴回落，最终在水槽中平静下来。
全景、撞击、俯视、侧视四个机位围绕同一水槽。

首次启动需要编译模拟与渲染内核，可能需要一分钟以上。窗口在准备完成
后打开，编译缓存位于 `water/.taichi-cache/`。

## 控制

| 操作 | 功能 |
|---|---|
| 左键拖动 / 右键拖动 | 旋转 / 在槽区附近平移 |
| W、S 或上下方向键 | 拉近 / 拉远 |
| 1 / 2 / 3 / 4 | 全景 / 撞击近景 / 俯视 / 侧视 |
| 空格 / N | 暂停继续 / 暂停时推进一帧 |
| A / H | 自动环绕 / 显隐面板 |
| R | 重置流体，重新释放水柱 |
| P / Esc | 保存截图 / 退出 |

面板中 `Viscosity` 调节 XSPH 速度平滑强度，`Vorticity` 调节涡度约束，
`Foam gain` 调节泡沫显示，`Particle radius` 调节粒子绘制半径，
`Spray gain` 调节喷溅亮度，`Edge fade` 调节薄水边缘的透明过渡。
`Water clarity` 调节水体吸收，光照、曝光、时间速度沿用前面的 demo。

## 粒子与交互计算

- **核单位制：** spiky 梯度幅值按 1/h⁴ 缩放，pbf2d 参考实现的常数只在
  核半径接近 1 时稳定。模拟在核单位下运行（h = 1.1，与参考实现一致），
  渲染时再换算回米制，常数无需缩放。子步长按 pbf2d 的重力位移比匹配，
  与粒子间距无关。
- **PBF 求解：** 每子步预测位置、均匀网格邻域搜索、5 次迭代的密度约束
  求解（poly6 密度、spiky 梯度、抗拉伸修正），再投影回槽壁、天花板与
  立柱，由位移更新速度。静止密度取实测晶格密度，约束在初始堆积处为零，
  水体体积守恒，不会像 pbf2d 那样沉降损失约三成高度。
- **涡度与黏性：** 速度级叠加涡度约束（恢复湍流细节）与 XSPH 速度平滑
  （人工黏性），强度可在面板实时调节。边界接触带切向摩擦，
  速度钳制防止异常步长。
- **泡沫与喷溅：** 泡沫由空化（密度相对自身前值的下降）与高速共同驱动，
  静止水面不会误报；喷溅粒子按速度阈值从体水中分离，单独做透明合成。
- **屏幕空间表面：** 静态水槽先着色到背景缓冲，同时记录背景深度；粒子把最前深度、
  厚度、泡沫溅斑进屏幕缓冲，逐像素与背景深度比较，被槽壁或立柱遮挡的
  粒子不参与合成，水面不会爬上固体表面。深度两次平滑融合相邻球冠，法线
  由深度梯度重建，菲涅尔混合天空反射与折射。折射光线解析求交槽底与槽壁，
  按路径长做 Beer–Lambert 吸收；薄覆盖区域（水滴、水缘）按覆盖率降低
  不透明度与吸收，避免孤立水滴发黑。抗粘抖动由位置与步数哈希，暂停重绘稳定。

## 回归与边界

本轮已通过 15 项 CPU 回归检查，并用 Metal 实际验证溃坝、撞击、回落与
静止各阶段的多个机位；原生窗口连续显示三帧。960 × 600 稳态渲染约
12 ms/帧（含一帧两次 PBF 子步）。

```bash
uv run python -m unittest water.tests.test_demo_09 -v
```

检查覆盖核函数与 Python 镜像一致性、静止密度解析值、溃坝全程域内有限、
静置收敛、邻域搜索与暴力对照、立柱投影、子步预算、重复运行一致性、
无窗口渲染、暂停重绘稳定性、四个机位画面、水面与背景差异、
溅斑背景遮挡门控、重置恢复。

屏幕空间重建不处理遮挡关系的层间顺序，密集重叠处厚度只是近似；
孤立水滴受球状 splat 限制呈颗粒感。浮点原子求和顺序随调度变化，
长时间运行存在混沌发散，单步与单帧内结果一致。
